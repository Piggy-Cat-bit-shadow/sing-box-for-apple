# Product and scope

Jiejiebox is a non-official Apple fork of SagerNet's `sing-box-for-apple`. It overlays a preserved Hako experience on **iPhone only**, keeps iPad and macOS official UI, and shares one business/network/configuration layer. The core comes from the related Jiejiebox sing-box line, but the exact parent pin is `EXTERNAL-CHECK-REQUIRED` here.

Fork-delta rule: upstream is the implementation fact source for unchanged code; this fork and its commits are the product-difference source. Do not turn this into a complete upstream encyclopedia.

Current shipping/product truth must be resolved from the selected product ref. This baseline records the NE closure head, while `jiejiebox/integrated` is the integration lineage. The GitHub default `dev` is explicitly historical/default governance state, not evidence that it contains the Hako product.
